Without one, default copyright applies: no one else has permission to use, copy,
modify or distribute this software. That is almost certainly not the intent for a
public beta.

Pick one before distributing. The usual options:

- **MIT** — permissive. Anyone may use it, including commercially, provided the
  copyright notice is kept.
- **Apache 2.0** — permissive, and adds an explicit patent grant.
- **GPL-3.0** — copyleft. Derivative works must also be open source. This is what
  mdfried, one of the projects referenced here, uses.

Once chosen, add a `LICENSE` file at the repository root and replace this page
with its text.
