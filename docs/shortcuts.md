# SHORTCUTS

Every shortcut, by section. `EVM` and `SOL` mark which
dashboard has it.

## TRADE

| key | does | where |
| --- | --- | --- |
| `b` | buy | both |
| `s` | sell | both |
| `x` | sell all | both |
| `h` | holdings | EVM |
| `M` | move funds | both |

## LIQUIDITY

| key | does | where |
| --- | --- | --- |
| `a` | add liquidity | EVM |
| `r` | remove liquidity | EVM |

## DISCOVER

| key | does | where |
| --- | --- | --- |
| `f` | find market | both |
| `F` | verified tokens | EVM |
| `k` | leaderboard | EVM |

## POOL

| key | does | where |
| --- | --- | --- |
| `p` | add pool | both |
| `Del` | deselect the pool | EVM |
| `d` | multi-pool view | EVM |
| `e` | auto arbitrage | EVM |

## SIZE

| key | does | where |
| --- | --- | --- |
| `[` | decrease buy size | both |
| `]` | increase buy size | both |
| `;` | decrease buy step | EVM |
| `'` | increase buy step | EVM |
| `(` | decrease sell size | EVM |
| `)` | increase sell size | EVM |
| `(` | decrease slippage | SOL |
| `)` | increase slippage | SOL |
| `{` | decrease slippage | EVM |
| `}` | increase slippage | EVM |
| `{` | decrease priority fee | SOL |
| `}` | increase priority fee | SOL |
| `<` | tighten price impact limit | EVM |
| `>` | loosen price impact limit | EVM |
| `0` | price impact limit off | EVM |
| `P` | auto priority on/off | SOL |
