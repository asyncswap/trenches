# KEYS

Every shortcut, by section. `EVM` and `SOL` mark which
dashboard has it.

## TRADE

| key | does | where |
| --- | --- | --- |
| `b` | buy | both |
| `s` | sell | both |
| `x` | sell all | both |
| `h` | token holdings | EVM |
| `M` | move funds to an address | SOL |

## LIQUIDITY

| key | does | where |
| --- | --- | --- |
| `a` | add liquidity | EVM |
| `r` | remove last liquidity | EVM |

## DISCOVER

| key | does | where |
| --- | --- | --- |
| `f` | find market | both |
| `F` | verified tokens | EVM |
| `k` | leaderboard | EVM |

## POOL

| key | does | where |
| --- | --- | --- |
| `p` | select pool | EVM |
| `p` | add token by address | SOL |
| `Del` | deselect the pool | EVM |
| `d` | multi-pool view | EVM |
| `e` | auto arbitrage | EVM |

## VIEW

| key | does | where |
| --- | --- | --- |
| `t  o  l  c` | trades · orders · logs · chart | both |
| `O  → ←` | cycle panels | both |
| `↑ ↓` | scroll | both |
| `,  .` | candle interval −/+ | both |
| `m` | chart: price / market cap | both |
| `L` | PnL calendar | EVM |

## SIZE

| key | does | where |
| --- | --- | --- |
| `[  ]` | buy size −/+ | both |
| `;  '` | buy step finer/coarser | EVM |
| `(  )` | sell size −/+ | EVM |
| `(  )` | slippage −/+ | SOL |
| `{  }  0` | slippage −/+ | EVM |
| `{  }` | priority fee −/+ | SOL |
| `P` | auto priority on/off | SOL |

## MODE

| key | does | where |
| --- | --- | --- |
| `T` | theme picker | both |
| `$` | display currency | EVM |
| `g` | profit guard on/off | EVM |
| `n` | buy dedup on/off | EVM |
| `C` | change chain | both |
| `W` | change wallet | both |
| `D` | docs | both |
| `q` | quit (Q skips the prompt) | both |
| `?` | help | both |
