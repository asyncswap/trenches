# TRENCHES

A terminal trading bot.

**Available on**

- Robinhood Chain
- Solana

**Supported protocols**

- Uniswap V3
- Uniswap V4
- pons.family
- pump.fun
- PumpSwap AMM

**Nothing here trades by itself.** Every order is a key you pressed. Copy modes
only ever pre-fill a size — they never submit.

Use `tab` to move between these documents, `↑` `↓` to scroll, `esc` to go back.

## Start here

- **Overview** — the screens, and the two numbers that decide whether a trade is
  a good idea.
- **Keys** — every binding, including what separates `s` from `S` and `f` from
  `F`.
- **Accounts** — how to make one, and what the bot will never do with it.
- **Config** — where settings live, and how to set an API key.
- **Terms** and **Privacy** — what this software promises, which is very little.
- **License** — how you may use and share it.

## Before you trade real size

Read the **price impact** section in Overview. On a thin pool it is the
difference between a fill and dumping on yourself.
