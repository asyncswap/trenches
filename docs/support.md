# SUPPORT

This terminal is built in the open — the code that holds your keys is code
you can read. Here is how to get help, and how to help back.

## Report a bug

Bugs are the point of a beta. Open an issue with:

- The build you are running — bottom-right corner of the dashboard, or
  `trenches --version`.
- What you expected, and what happened instead.
- The session log if it is relevant — `~/.trenches/` keeps one per session.

File it at github.com/asyncswap/trenches/issues.

## Contribute

The source is AGPL-3.0 and public. Pull requests are welcome. Unsure whether
something is worth building? Open an issue and ask first — a ten-minute
conversation beats a thousand-line surprise.

## Trenches Pro — coming

The app is free and stays free. What costs real money to run — fast RPC
endpoints, websockets that do not rate-limit you mid-launch, priority-fee
estimates, deep candle history — is being built as a hosted service: one URL
you paste into `e` (endpoints) and this terminal gets faster. If you would
pay for that, say so on the issues page; the first people to ask will shape
what it becomes.
