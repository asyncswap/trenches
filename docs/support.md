# SUPPORT

Here is how to get help, and how to help back.

## Report a bug

Bugs are the point of a beta. Open an issue with:

- The build you are running — bottom-right corner of the dashboard, or
  `trenches --version`.
- What you expected, and what happened instead.
- The session log if it is relevant — `~/.trenches/` keeps one per session.

File it at github.com/asyncswap/trenches/issues.

## Contribute

The source is AGPL-3.0 and public. Pull requests are welcome. Unsure whether
something is worth building? Open an issue and ask first — a ten-minute
conversation beats a thousand-line surprise.

## Trenches RPC — the hosted endpoint

One key covers everything the terminal needs — both chains, websockets,
pooled providers with failover. Sign in at
[rpc.trenches.sh](https://rpc.trenches.sh).

- **Free**: 10 requests/second — enough to run the terminal.
- **Pro**: $119/month, 10M requests included. Uncapped.
